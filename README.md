# Nino do Trabalho (kit)

Kit pré-pronto para montar o assistente de marketing no trabalho: vault no Obsidian, agentes e hooks, mais uma página de onboarding para responder junto com a gestão.

## O que tem aqui
- `onboarding/`: página estática de briefing (identidade visual da empresa). Publicada na Vercel. As respostas ficam só no navegador de quem preenche.

## Em construção
- `vault/` (constituição, estrutura de pastas, índices)
- `agentes/` (time de marketing)
- `hooks/` (painel de início e captura, sem voz)
- `INSTALACAO.md` (Maestri, Obsidian, Claude Code, skills)

## Regras
- Nenhum dado pessoal da Julia nem dado interno da empresa entra neste repositório.
- Nenhuma chave, senha ou token no repositório.
