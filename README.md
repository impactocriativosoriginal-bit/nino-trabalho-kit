# Nino do Trabalho (kit)

Kit pronto para montar o assistente de marketing no trabalho: vault no Obsidian, time de agentes, hooks e skills, mais uma central de onboarding para responder o briefing junto com a gestão.

**Central de onboarding:** https://promaxima-onboarding.vercel.app
**Instalação:** [`INSTALACAO.md`](INSTALACAO.md)

## O que tem aqui
| Pasta | O que é |
|---|---|
| `onboarding/` | Central em 6 abas (briefing, time, skills, instalação, repositório). Publicada na Vercel |
| `vault/` | Constituição (`.claude/CLAUDE.md`), pastas com índice, foco, todo, modelo de marca |
| `agentes/` | Pauta, Verbo, Gigi, Senna, Hel, Mel (+ Duda no Codex, em `codex/`) |
| `hooks/` | `painel.ps1` (início do dia) e `captura.ps1` (protocolo de captura), sem voz |
| `skills/` | `briefing`, `save`, `criar-pagina` |
| `marca/` | Logo e tokens de identidade da ProMáxima |
| `instalar.ps1` | Monta o vault a partir do kit |

## Regras
- Nenhum dado pessoal da Julia nem dado interno da empresa entra neste repositório.
- Nenhuma chave, senha ou token no repositório.
