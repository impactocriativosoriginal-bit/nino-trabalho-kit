# producao/ · Índice de contexto
> Mapa desta pasta. Ler antes de procurar qualquer coisa aqui dentro.
> Última atualização: 2026-11-16

## O que é esta pasta
Tudo que está sendo feito. Cada peça mora numa pasta `YYYY-MM-DD-tema/` dentro do tipo certo.

## O que tem aqui
| Pasta | O que é | Quem faz |
|---|---|---|
| `posts/` | Legendas, artes de feed, carrosséis, stories | Verbo e Gigi |
| `impressos/` | Folder, cartaz, cartão, papelaria | Gigi |
| `videos/` | Roteiro, storyboard, composição HTML e vídeo exportado | Senna |
| `paginas/` | Páginas, apresentações em HTML, materiais visuais | Gigi (skill `criar-pagina`) |

## Quando abrir o quê
- Retomar uma peça → pasta dela, ler o `peca.md` (briefing, status, versões)
- Peça nova → criar a pasta com `peca.md` (marca, formato, objetivo, prazo, aprovador, status)

## Padrões e pegadinhas
- Peça publicada não é apagada: vai para `arquivo/` com timestamp depois de um tempo.
- Arquivo pesado (vídeo, PDF de impressão) fica fora do Git se passar de poucos MB.
- Nada é publicado sem revisão da Julia.
